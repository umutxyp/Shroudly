## Shroudly 2.6.71

**Windows 7 and 8: Start and Stop work again, and Advanced mode says what is really in its way.**

### Windows 7, 8 and 8.1
- Since 2.6.34, every Start and Stop on Windows 7 and 8 ended with "Start failed: app.setProxy is not a function": the Windows 7 and 8 build runs an older Electron, which does not have that function. Fixed, and a test now keeps such newer functions out of the code those systems run.
- On Windows 7, Advanced mode said that security software blocked its driver (error 577). It was not an antivirus: Windows 7 cannot check the driver's SHA-2 signature without Microsoft's update KB4474419. The app now says that, with the update to install, and does not ask for administrator permission again and again in the same session.
- Tor's bridges for your country are now fetched on Windows 7 and 8 too.

### Every app
- After an update, the "What's new" window inside the app showed 2.6.64's notes under every newer number (2.6.65 to 2.6.70). The notes are written for this version now, a test keeps them that way, and notes already shown are never shown again.

### Windows
- The 32-bit Shroudly on a 64-bit Windows said that Advanced mode is "not available on this processor". It now says that the 64-bit Shroudly has it, to install over this one (settings stay).
