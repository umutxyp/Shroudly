## Shroudly 2.6.50

**Android TV and Google TV, and a site whose server answers with the wrong certificate now opens.**

### Android TV and Google TV
- The Android APK now runs on Android TV and Google TV (Android 8 or newer). It appears in the TV's own row of apps with its own banner and works with the remote. Like on a phone, every app on the TV goes through it: YouTube, browsers, streaming apps.
- What the remote has reached stands out: a ring in your accent colour around it, round on the switch.
- "Apps that skip Shroudly" lists the TV's apps too, including ones that only open from the TV's launcher. The Quick Settings tile row is left out, since a TV has no such panel.
- Install it with a file manager or "Send files to TV". Android TV asks once to allow the VPN, as a phone does.

### A server that answers with its own certificate ([#68](https://github.com/umutxyp/Shroudly/issues/68))
- Some protection services in front of sites (DDoS-Guard in the report) cannot read a ClientHello that is sent in two TLS records. They answer with their own certificate instead of the site's, and the browser shows `NET::ERR_CERT_AUTHORITY_INVALID`. Shroudly saw a completed handshake and kept the technique.
- Now Shroudly notices when the browser turns down the server's handshake right after a technique. For that site it stops using that kind of technique for a few hours and opens the next connection with another one. Reload the page once and it opens.
- On the computer, Android and iPhone alike (the same engine). The log says when it happens, and the technique that replaced it is remembered.

### Windows ([#69](https://github.com/umutxyp/Shroudly/issues/69))
- Advanced mode said "your antivirus blocked Shroudly" and "Advanced mode's files are missing" whenever Windows answered "not found", even with every file in place and no antivirus running. Now it says that only when a file really is gone. Otherwise it gives Windows' own error code.
- The "V2Ray / Clash is running too" warning came up whenever such a program had anything running, such as Clash Verge's background service or a core left behind after its window was closed. Now it comes up only while that program's tunnel is actually on. A program that takes over the system proxy is still named when it does.

### Also
- Tests: a stand-in for such a server and a browser that refuses it, in TLS 1.2 and TLS 1.3, with a sanitizer build too; the Android end-to-end test (VPN, DNS, Proxy only, updates) on a Google TV emulator, and the app on a 1080p Google TV with only the remote: the VPN allowed, protection on, every screen reached.

Everything from [2.6.49](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.49) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.50 itself.
