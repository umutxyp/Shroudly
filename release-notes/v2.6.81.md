## Shroudly 2.6.81

**Tor starts again on Android; with QUIC off, calls and games on UDP 443 go through again; the country is not taken from a remembered shutdown where the time zone names another; signed remote settings, so a technique, a Tor bridge or a rule can change without a new version.**

### Android
- The last way out (Tor) ended with code 1 at once on phones after 2.6.80 (Tor 16.0.1 there); Android is back on Tor 16.0, which ran on them, while the computers keep 16.0.1. Tor's own warnings and errors now go into the log, a few a start, so a failure says why.

### Android, iPhone, iPad and the Mac
- QUIC turned off dropped every datagram to UDP port 443, which cut what uses that port for itself, calls' relays among them (WhatsApp calls stuck on "connecting"). Now only a flow that starts as QUIC is turned away (its Initial answered, as in 2.6.80); anything else on 443 goes as any UDP does.

### Every system
- Remote settings: Shroudly reads remote.json from its repository (through itself while protection is on, from GitHub or its jsDelivr mirror) every six hours. It is data, never code, and is used only when its ECDSA P-256 signature checks against the key every app carries, its number is higher than the one in use and it has not expired; the last good one is kept. It can change, by platform, country and version: the techniques the engine starts with (an allow-list: never a server, a file, a port or an address), the decoy names, Tor's bridges or whether Tor starts at all, the phones' default for "Turn off QUIC" (a choice the user made stays), and when "Something not working?" shows. A new one takes effect at once.
- The Android Tor bundle is now checked at build time for libraries no Android has: 16.0.1's asked for libz.so.1, which is why Tor never started on phones in 2.6.80.
- A country remembered from a shutdown is used only where the time zone names no place (UTC and the like), and a site of a listed country answering alone counts as a national-only network only where the time zone is that country's: a phone in Qatar had kept Iranian decoy names.
- Where torproject.org is cut, the computers fetch Tor 16.0.1 from its mirror on Shroudly's GitHub again (the mirror for 16.0.1 was missing in 2.6.80).
