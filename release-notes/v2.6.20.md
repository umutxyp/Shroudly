## Shroudly 2.6.20

**Advanced mode works on every Linux with nothing to install, steps aside for a game's anti-cheat, and reaches apps in a sandbox.**

### Linux: Advanced mode with nothing to install
- On Linux, Advanced mode needed a library (libnetfilter_queue) that Arch, CachyOS and most minimal installs do not have. There, Advanced mode could not be used at all, and Settings only showed a command to install it. Programs that ignore the proxy, such as Roblox through Sober or a bot, stayed blocked.
- Shroudly now talks to the kernel's packet queue itself, so Advanced mode works on every distribution as it comes. Shroudly turns it on by itself when such a program is stopped by the network (since 2.6.16), and Linux asks for your password.
- Apps in a sandbox (Flatpak, Snap), whose connections the system does not name, are now seen too when the network sends them to a block page.

### Games with an anti-cheat
- Anti-cheats such as BattlEye, Easy Anti-Cheat, Vanguard and FACEIT refuse a game, or drop it from its servers, while a packet driver like the one Advanced mode uses is loaded. GTA V shows this as "Rockstar Games: connection error". Shroudly already never turned Advanced mode on by itself during such a game. But when Advanced mode was already on and the game was started afterwards, it stayed on.
- Now, when a game with an anti-cheat starts while Advanced mode is on, Advanced mode steps aside and tells you in one line. It comes back by itself when the game closes; Windows asks for permission again. If you turn it on yourself while the game is open, that is left to you.

### A filter that looks for the site's name anywhere
- Some filters do not read the handshake at all. They drop any packet in which the blocked domain's bytes appear. Shroudly's first five techniques all cut the name near its start, which leaves the domain whole. On a network that also drops silently, a page then took 15 seconds and only opened on a reload.
- The technique that cuts the name in the middle now comes first. It does everything the cut at the start does against filters that read the handshake, and it also beats these. A page behind such a filter now opens on the first try.

### Tested on the networks people report from
- A new lab in the automatic tests puts the engine behind real filters on every change:
  - filters that drop the connection, or reset it, when they see the name;
  - addresses blocked outright, where the network's DNS knows another address, knows it only slowly, or gives the same blocked address;
  - names that nobody filters.
- For each of these, the lab checks that the site opens, or that Shroudly says why it cannot.

Everything from [2.6.19](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.19) is included. Desktop users update automatically; the Android app tells you that 2.6.20 is out.
