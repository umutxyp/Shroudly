## Shroudly 2.6.57

**Statistics cards that line up on every screen, a better Apple TV layout, Shroudly's own names safe from blocking, and Follow Shroudly with the developer's accounts first.**

### Layout
- **Statistics:** on iPhone and iPad the Connections card's second line (the total and the ads blocked) left the Uptime card beside it shorter and centred; the cards of a row are now equally tall, their contents at the top, and an iPad no longer stretches them. On computers, the values of a row stand level too.
- **Apple TV:** the statistics get a wider column for the TV's larger type, so no word is cut off ("Connect…", "Uptime…"), and the buttons below have room between them.
- **Computers:** in a maximised window each screen keeps a readable width, centred, instead of rows stretched from edge to edge.
- Checked with screenshots of every screen at several sizes (from a 360-pixel window to full screen, iPhone SE to iPad, Apple TV) and in English, German, Persian (right to left), Burmese and Turkish.

### Connections
- The names Shroudly itself needs (its encrypted DNS servers, Tor, codeshare.me, GitHub for updates, your own server) have no **Block** button any more, cannot be typed in to block, and the computer refuses it if asked anyway: blocking one would only break Shroudly. A name blocked before can still be allowed again. On computers, Android and the App Store apps.

### Follow Shroudly
- The developer's accounts come first, everywhere (the apps, the README and the guides): news, new versions and urgent notices are posted there. Codeshare's accounts follow.

### Security
- Code scanning: the tests that talk to local TLS stand-ins now check the certificate against the test certificate instead of turning verification off.
