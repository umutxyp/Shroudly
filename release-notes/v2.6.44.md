## Shroudly 2.6.44

**Fixes for Windows, antivirus programs, updates and Android networks.**

### Windows
- **Shroudly now works even when Windows' PATH is broken.** If another program had removed or reordered Windows' own folders in PATH, Shroudly could not start the system tools it needs. It now puts those folders first for itself. ([#61](https://github.com/umutxyp/Shroudly/issues/61))
- **Installing over an old version works.** If the old version's uninstaller failed, the new installer used to stop. It now carries on and replaces the old files.
- **Antivirus programs flag Shroudly less often.** The engine now names its product, company and version, and Shroudly no longer does things that look suspicious to antivirus programs (such as running a second background copy of itself).
- **If an antivirus program blocks Shroudly, Shroudly says so.** It tells you that an antivirus program removed or stopped part of Shroudly and what to do, instead of protection silently not starting. The README has a new section on antivirus programs.

### All computers
- **Updates are safer.** A full disk, a download that is cut off or an install that does not complete no longer leaves Shroudly closed or half-quit. Shroudly keeps running, says what happened and offers to try again.
- **A damaged settings file no longer stops Shroudly.** Protection and "Start at sign-in" stay as you left them.
- **"Not working yet" is shown when your browser bypasses Shroudly,** so you are not told you are protected when you are not. The status and Start/Stop button now always stay on screen, even in small windows.
- **Faster when encrypted DNS is blocked:** new sites no longer wait 4 seconds each.
- **A Wi-Fi drop or a network switch is no longer mistaken for censorship,** so Shroudly does not switch techniques for no reason.
- **Linux:** the AppImage starts without libfuse2 (Ubuntu 22.04+ and others). deb, rpm and pacman installs ask for your password once when you install an update, and "Start at sign-in" follows the AppImage when it updates.

### Android
- **Protection comes back on by itself after Shroudly is updated.**
- **Shroudly follows the network your phone actually uses,** so moving between Wi-Fi and mobile data no longer leaves apps without internet.
- **Proxy only:** if another app is using port 10808, Shroudly uses another port and tells you which one.
- **Google Play copy:** Shroudly now shows Google Play's own update prompt when a new version is out, so you can update right inside the app.

Everything from [2.6.43](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.43) is included. Desktop users update automatically; the Android app tells you that 2.6.44 is out.
