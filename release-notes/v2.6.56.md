## Shroudly 2.6.56

**Windows 7, 8 and 8.1, 32-bit Windows and 32-bit ARM Linux; League of Legends and VALORANT where Riot Games is blocked ([#76](https://github.com/umutxyp/Shroudly/issues/76)); Advanced mode repairs "driver not found" by itself; Tor only as the very last way, and said when used; phones name a DNS profile in the way; Follow Shroudly.**

### Windows 7, 8 and 8.1, 32-bit Windows, 32-bit ARM Linux
- **Windows 7, 8 and 8.1:** an installer of their own (`Shroudly-2.6.56-Windows7-8-Setup.exe`), one file for both 32- and 64-bit Windows. The same app, window and engine, on Electron 22, the last that runs there; Windows' Universal C runtime comes beside the engine, so no Windows update is needed. It updates from its own feed and is never offered the Windows 10 build. Not there: the last way out through Tor (the Tor Project's Tor needs Windows 10) and Advanced mode on 32-bit Windows. The Windows 10 installer, run on Windows 7 or 8, offers to download this one.
- **32-bit Windows 10 and 11:** `Shroudly-2.6.56-Windows-ia32-Setup.exe`, with Tor's 32-bit build for the last way out.
- **32-bit ARM Linux** (Raspberry Pi OS 32-bit and other armhf systems): an AppImage and a `.deb`. Everything but Advanced mode and Tor, which have no 32-bit ARM build.
- Each of them is installed and started before the release is published: the Windows ones on Windows, the 32-bit ARM ones in a 32-bit ARM Debian under QEMU.
- **Android:** the main APK already runs on 32-bit ARM phones; the smaller *arm64* APK is for 64-bit ARM phones only, which its label now says.

### Riot Games (computers)
- Riot's programs (League of Legends, VALORANT, the Riot Client and the installer from leagueoflegends.com) never use the system proxy, so on a network that blocks Riot the website opened through Shroudly while the installer said *"No internet connection"*. Shroudly now notices when this network blocks Riot (from a Riot site you open, or with Riot's client installed) and turns on **Games and apps mode** by itself, as it already does for Roblox, so Riot's programs go through Shroudly too.
- Riot's own programs need to be started again after the mode comes on (a running program keeps the settings it started with).

### Advanced mode on Windows
- *"Windows could not start the WinDivert driver (error 2 or 3) although Advanced mode's files are all in place"* is now repaired by Shroudly itself:
  - another program that used the same driver (GoodbyeDPI, zapret, some VPNs) can leave a driver service behind pointing at a folder it deleted; Shroudly removes such a service when it is stopped, and starts its own;
  - when Windows cannot load the driver from Shroudly's folder (a network or substituted drive, a folder only your user can see), Shroudly copies the driver, checked byte for byte, to `Common Files\Shroudly` (a folder only administrators can change) and starts it from there.
- The log says what was repaired, or, if it still fails, what was tried.
- Both cases are tried on the real driver on every build.

### Tor is the last of all ways, and you are told when it is used
- Shroudly uses Tor only for a site that every technique failed to open, and only when your own server is not set. When Advanced mode comes on, the sites Tor carried until then try Advanced mode first.
- When a site opens only through Tor, Shroudly now says so, in words for the device: a notification on a computer and a phone (it is slower, and some sites ask for a captcha), a message on the screen on Android TV (videos from it can load slowly). Once per site, and at most once every 15 minutes.

### Phones, tablets and TVs say what is in the way
- **A DNS profile or app in the way** (AdGuard, NextDNS, 1.1.1.1, a school or work profile, Android's Private DNS) answers apps' lookups before Shroudly, so blocked apps get its answers. Shroudly now notices it (apps' connections keep arriving by address, none by name) and says where to turn it off: a notification and a line on Android (on a TV, on the screen), a card and a notification on iPhone, iPad and Mac.
- **Right after Start**, for two minutes: an app that was already open may hold its old connections; if one does not connect, close it and open it again once.

### Follow Shroudly
- **A Follow tab of its own** in every app (computers, Android phones and TVs, iPhone, iPad, Mac, Apple TV): Codeshare's accounts and its developer's. On a TV, where links do not open, the addresses are shown to open on a phone.
- **About** in the Android and Apple apps now links Codeshare's site too.

Everything from [2.6.55](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.55) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.56 itself.
