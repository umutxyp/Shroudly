## Shroudly 2.6.6

**A security update of the app's built-in browser engine, and the Android Quick Settings tile opens Shroudly when you press and hold it.**

### Security
- **Electron 43.7.6**, which fixes a flaw where a page's pointer-lock permission request could be attributed to the wrong frame ([GHSA-x562-297c-g43g](https://github.com/advisories/GHSA-x562-297c-g43g)). Shroudly's window shows only its own pages, so this could not be reached from a website, but the fix is in now.
- Two findings of GitHub's code scanning are fixed: the short log (Copy logs) no longer uses a pattern that slows down on very long lines, and a test helper can no longer write past its buffer.

### Android
- **Press and hold the Quick Settings tile** to open Shroudly, instead of Android's App info ([#35](https://github.com/umutxyp/Shroudly/issues/35)).

Everything from [2.6.5](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.5) is included: your own DNS server (DoH, DoT, TCP or plain DNS), proxies left behind by other programs found and fixed, Android screens on small phones and with large text. Desktop users update automatically; the Android app tells you that 2.6.6 is out.
