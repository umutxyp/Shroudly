## Shroudly 2.4.0

### "It works in my browser but not in the Discord app"
Three people reported this, and it is not the bypass failing — Discord's own servers, gateway included, connect fine through Shroudly. The cause is simpler: **a program reads your connection settings once, when it opens.** If Discord was already running when you turned protection on, it is still using the unprotected connection it started with.

Shroudly now notices this for you. When protection starts, it checks which programs are already open and tells you — by name — which ones need restarting. No more guessing.

> Same reason Firefox can behave differently from Chrome or Brave: Firefox reads the setting from its own preferences, and a sandboxed (Snap/Flatpak) install cannot see the system setting at all. Settings → Network Settings → **Use system proxy settings**.

### Make it yours
**Nine accent colours** and a **liquid glass** look, both in Settings → Appearance. Only the accent changes — every text contrast stays exactly as designed, so no colour you pick can make anything harder to read. The glass effect switches itself off on systems set to reduce transparency.

### Faster, and fewer things it gets wrong
Found by auditing the previous release and reproducing each one:

- **Apps where the server speaks first** — SSH, mail, game clients, and every connection your browser opens in advance — were stalled for four seconds each. Now **3 milliseconds**.
- **A slow website was mistaken for a blocked one.** A site taking three seconds to answer was cut off, asked again, and logged as censored. It now loads in its own time, asked once.
- **A failed handshake was being remembered as a success**, so a technique that broke a site could be reused on it.
- Two unnecessary waits per protected connection removed — roughly **twice as fast** on the common path, and far more than that on Windows.
- The Windows installer now stops with a clear message on **Windows 8.1 and earlier**, instead of installing something that cannot start.
- The **.deb package installs on current Ubuntu and Debian again** — it declared dependencies that no longer exist on those systems.

### Smaller things you might have noticed
- Numbers follow the language you chose, not your operating system's. An Arabic window no longer shows European separators; Persian and Bengali get their own digits.
- The speed graphs show a resting line before any traffic, instead of two empty bands.
- Entries you type into the site list that cannot work are removed and named, rather than silently breaking the file your browser uses to route every request.
