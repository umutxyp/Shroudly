## Shroudly 2.5.3

- **Protection stays the way you left it.** If you stopped it, it no longer turns itself back on: not when the computer wakes up, not when the screen is unlocked or the lid opened, not after an update restarts Shroudly, a crash or a reboot. Only Start and Stop change it, in the window or the tray, on every system. Thanks for the report in [#8](https://github.com/umutxyp/Shroudly/issues/8).
- **Half the memory in the background.** The window is now closed for real, not just hidden, when you send it to the tray, and also when it has sat unused for three minutes; protection keeps running without it, and the window opens again from the tray, the Dock or by starting Shroudly again. Protecting in the background, measured the same way on each system:

  | System | 2.5.2 | 2.5.3 |
  |---|---|---|
  | Windows (Intel / AMD) | 106 MB | 56 MB |
  | Windows (ARM) | 75 MB | 31 MB |
  | macOS (Apple Silicon) | 140 MB | 66 MB |
  | macOS (Intel) | 146 MB | 75 MB |
  | Linux (x64) | 121 MB | 71 MB |
  | Linux (ARM) | 137 MB | 70 MB |

- **No more requests to Google from the window.** On Windows and Linux the window's spellchecker downloaded dictionaries from Google whenever it opened. It is off; nothing in the window needs it.
- **A smaller safety net.** The helper that puts your network settings back if Shroudly is killed now needs about 1 MB instead of 18 MB.
- Smaller things: each language loads on its own instead of all 31 at once; the window is drawn without the GPU, which kept memory for nothing; and Shroudly's own requests (the live count, update checks) go straight to the engine instead of through the system proxy.

Everything from [2.5.2](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.2) is included. Users of 2.0.4 and later update automatically.
