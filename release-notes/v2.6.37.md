## Shroudly 2.6.37

**The DNS server can be reached through your own proxy (#58).**

### DNS server through a SOCKS5 or HTTP proxy
- Settings → DNS server has a new optional field, *Through a proxy*. Type a proxy like `socks5://127.0.0.1:1080` or `http://127.0.0.1:8080`, with `user:password@` in front of the host if the proxy asks for a login.
- Only the connections to the DNS server you chose go through it: DNS over HTTPS, DNS over TLS and DNS over TCP. Everything else goes as before. This is for a DNS server whose address is blocked on your network.
- The proxy looks up the server's name itself, so nothing about the server is asked on your network first.
- When you press *Use*, Shroudly asks the server through the proxy first, so you see right away whether it answers that way. A wrong password or a proxy that is not running shows up there.
- Plain DNS (UDP) cannot go through such a proxy, so the field is hidden for it.
- On desktop and Android, in all 31 languages.

Everything from [2.6.36](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.36) is included. Desktop users update automatically; the Android app tells you that 2.6.37 is out.
