## Shroudly 2.6.46

**For internet shutdowns: Shroudly says when only the country's own network works, goes through a server of your own, shares a connection with people you trust, and passes itself from phone to phone.**

### When only the country's network works
- **Shroudly tells a shutdown from "no internet".** When the rest of the world is cut and sites inside the country still open, the window says **"Only this country's network works"**, on the computer and on Android, with a link to a guide in your language: what still works, and what to prepare. It checks by opening well-known sites inside the country with their real certificates, so a hotel's or café's sign-in page is not taken for a shutdown.
- **Your own server** (Settings → More settings; on Android, Settings → Advanced): every site goes through a server you name, given as a `socks5://`, `http://` or Shadowsocks `ss://` link, the kind passed around for this. Shroudly opens a site through it before using it and says why if it does not work (no answer, a wrong password, a server that carries no sites); if it stops working later, the main window says so. The saved link's password is not shown. The server sees which sites you open: use only one you trust.
- **Share my connection** (computer; off until you turn it on): if your connection still reaches the world, people you give its link to use it through Shroudly, from **Your own server** or any Shadowsocks app (v2rayNG, Hiddify, Shadowrocket, sing-box…). On the same network at once; over the internet where your router opens a port (UPnP, taken away when sharing stops). They reach only sites, never your computer or home network, and nothing is recorded of what they open. **New link** ends the old one at once.
- **Share Shroudly** (Android, About; the APK from GitHub): sends the app itself to another phone over Bluetooth, a nearby-share app or a messenger, for when its download page cannot be reached.
- **The guide** to shutdowns, in all 31 languages, is in the [wiki](https://github.com/umutxyp/Shroudly/wiki/Shutdowns-en).

### Windows
- **Protection starts where Windows will not run `reg.exe`** ([#64](https://github.com/umutxyp/Shroudly/issues/64)): on a system that refuses it (even for an administrator), Shroudly reads and writes these settings itself. If Windows refuses the system proxy altogether, protection still runs and the window gives the address to set by hand, with a button to copy it.

### Also
- Shadowsocks works the same in every Shadowsocks app and in Shroudly, on every computer and on Android 8 and later, with every common method (ChaCha20-Poly1305 and AES-GCM): checked against shadowsocks-libev, the reference implementation.
- New text in all 31 languages; Amharic writes "ፕሮክሲ" for "proxy" everywhere.

Everything from [2.6.45](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.45) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.46 itself.
