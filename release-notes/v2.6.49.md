## Shroudly 2.6.49

**With your own server, DNS goes through it too: no DNS leak.**

### Your own server: DNS through it ([#67](https://github.com/umutxyp/Shroudly/issues/67))
- Websites went through your own server, but the encrypted DNS Shroudly looks names up with still went to the resolvers straight from your own connection. Nobody on the way could read the names, but the resolvers saw your real address next to the server's, which a DNS leak test shows.
- Now, with your own server set, **every** DNS question goes through Shroudly's engine and on through your server, in Automatic mode too, on the computer, Android, iPhone and iPad. Resolvers see only the server's address.
- A DNS server of your own goes through it as well; plain DNS is then sent over TCP, which a server carries. A proxy you set for your DNS server yourself ([#58](https://github.com/umutxyp/Shroudly/issues/58)) is used as you set it.
- While the server is down, DNS waits for it instead of going out directly, so nothing leaks then either.

### Also
- The server helper's `--remove` waits for everything running as its user to end before removing the user (Chromium's helpers can outlive the service by a moment).
- Tests: DNS through a SOCKS5 stand-in for the engine on every platform, with real resolvers over TLS, and that nothing goes straight out before the engine is up; plain DNS of one's own over TCP, not one UDP packet out.

Everything from [2.6.48](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.48) is included: the address sites see through your own server, Settings in four tabs, helping people in censored countries from a computer, a phone or a server, and a short note in your language after each update. Desktop users update automatically; the Android app from GitHub offers to install 2.6.49 itself.
