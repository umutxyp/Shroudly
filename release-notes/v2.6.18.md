## Shroudly 2.6.18

**Security update: Electron 43.8.1.**

### Security
- **Electron 43.8.1.** Two intermediate certificates of the eMudhra certificate authority were compromised. Websites signed through them are no longer trusted. Shroudly's window and its own connections (updates, the site list) run on Electron.
- **undici 7.30.1** and **fast-uri 3.1.9** fix a denial of service and several URI parsing issues in libraries used while building Shroudly.
- On Android, the online count's request names the same Electron version as the desktop app.

Nothing else changes. Everything from [2.6.17](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.17) is included. Desktop users update automatically; the Android app tells you that 2.6.18 is out.
