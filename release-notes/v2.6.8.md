## Shroudly 2.6.8

**Your names stay with your DNS: the network's own DNS is no longer asked about every site, and your own DNS server copes better with a lossy network.**

### DNS privacy ([#34](https://github.com/umutxyp/Shroudly/issues/34))
- Since 2.6.3, to open names that only the local network knows (a company's intranet, a VPN's own names, a hosts-file entry), the engine also asked your system's DNS about **every** new site name, in plain text. That showed those names to the network's DNS, and it is why a DNS test page listed resolvers you never chose.
- Now Shroudly's encrypted DNS (or your own DNS server) is asked first. The system's DNS is asked only about a name that has no public address there, so intranet and VPN names still open, and public site names are no longer shown to it.

### Your own DNS server
- **Plain DNS (UDP):** a question that gets no answer is sent again after 0.8 s, as any DNS client does. On a network that drops packets, an answer now comes in about a second instead of after the full wait, with no switch to the built-in DNS. This applies on the desktop and on Android.

Everything from [2.6.7](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.7) is included: the language setting on Android, the Off strategy (encrypted DNS only), your own DNS server. Desktop users update automatically; the Android app tells you that 2.6.8 is out.
