## Shroudly 2.6.55

**Connections by site, and blocking any of them ([#74](https://github.com/umutxyp/Shroudly/issues/74)).**

### Every platform (computers, Android, iPhone, iPad, Mac, Apple TV)
- **Connections by site:** what goes through Shroudly since protection started, listed by the site's name rather than by address (the name the connection was opened for, read from the connection itself), with the data each way, how many are open right now, and how each went out: straight, with a technique, through your own server, or through Tor. On computers under Stats; on Android, iPhone, iPad and Apple TV tap the Connections tile.
- **Block a site:** its open connections end at once, and new ones to it and to every name under it are refused. Type a name in the search box to block a site that has not shown up yet. Allow it again from the same list. The list of blocks is kept on your device only and never leaves it.
- **Shroudly's own names** (encrypted DNS, updates, the live count, Tor, your own server) are marked in the list; blocking one asks first, since it can stop sites from opening.
- Nothing is recorded: the list lives in memory while protection is on and is gone when it stops.

### Lighter again ([#75](https://github.com/umutxyp/Shroudly/issues/75))
- **Computers:** Tor no longer comes with the installer. It is fetched (about 20 MB, once, checked against the Tor Project's own hash) the first time a site needs the last way out, through Shroudly so a network that blocks torproject.org does not stop it. Expecting your connection to the world to be cut? **Settings → Connection → Get Tor now** fetches it ahead of time.
- **Android:** two more APKs next to the one for every phone: **arm64** for 64-bit ARM phones (most phones, about a third of the size) and **Lite**, without Tor, the size Shroudly was before 2.6.54. Each one updates to its own kind. Google Play already delivers only what a phone needs.
- None of this changes speed: the last way out is used only for a site no technique opens. Every other connection goes exactly as before, and the last way out can be turned off.

Everything from [2.6.54](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.54) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.55 itself.
