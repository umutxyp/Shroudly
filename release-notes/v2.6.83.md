## Shroudly 2.6.83

**Blocked sites open faster: a new one starts with what already opened other blocked sites on the network, the names of one service share what one of them finds, and a technique that keeps working is not checked again after a restart; new techniques (several TLS records, random-size segments, an urgent byte with a record cut, new cut places in the domain's own label, HTTP Host rewrites); Advanced mode gets a stronger way for servers nothing else opens and steps aside before a game's anti-cheat looks; remote settings fall back to their mirror.**

### Every system
- A blocked site the engine had never seen started with the untouched request, and behind a filter that drops without a word that was a second or more of silence before any technique, then the list a batch at a time, for every new name (a report from Türk Telekom: blocked sites opened visibly later than with a tool that applies one fixed method to everything, while the line itself was as fast through Shroudly as without it). Now, once one technique has opened two different blocked sites on this network, a new name races it against the untouched request: the untouched request still goes first with a short moment to itself, so a site that is not blocked goes untouched as before. It is forgotten when the network changes, and nothing is learned from it unless the untouched request is shown blocked.
- Names of one site or service opened at once share what one of them finds (YouTube's video servers and images, Discord's domains, Instagram's, X's), instead of each walking the list on its own.
- A learned technique is checked again half an hour after it last opened the site, not half an hour after it was learned: after a restart or a network change, sites learned earlier no longer race the untouched request on their first connection. A block that was lifted is still found.
- New techniques in Auto, at the end of the list so nothing before them moves: an urgent byte after the first and the record cut five bytes before the name's end (what many Türk Telekom users run), the same cut after a one-byte split, and a record cut in the middle of the domain's own label. New cut places for that label (googlevideo in rr3---sn-x.googlevideo.com), where a cut in the middle of a long CDN name fell in the subdomain. A batch of the search holds one more technique, so a name nothing opens still reaches the last way out no later than before.
- New fixed choices in Settings, applied to every site from the first packet: several TLS records, small random pieces, an urgent byte with a record cut. They are not in Auto's list: every technique added there is one more a site nothing opens walks before the last way out.
- Plain HTTP: Host header rewrites every server tried took (lower-case header name, mixed-case host, no space), tried only on HTTP connections.
- A newly opened blocked site's line says how long it took ("opened with X (3 tries, ipv4, 2.4 s)").
- Remote settings ask each source in turn until one gives a usable file: a file whose signature does not check (a mirror out of step, a captive portal's page), expired or older no longer ends the check at the first source.

### Windows, macOS and Linux
- Advanced mode steps aside as soon as a game's anti-cheat bootstrapper starts (Fortnite's launcher and Easy Anti-Cheat's _EAC_EOS program; BattlEye's _BE launchers): it used to wait for the service and the game to be seen together, after the anti-cheat had already scanned the drivers, and Fortnite kicked a player for a "forbidden tool".
- Advanced mode: a server whose decoyed first segment goes out again unanswered gets a stronger way for ten minutes: the decoy eight times, kept from the server by the TCP timestamp where the connection has one, and the real ClientHello cut after its first byte with the decoy's ClientHello in front of it (what opened YouTube's video servers on Rostelecom). Every other server goes exactly as before; the seqovl part is never larger than the real segment, for PPPoE lines.

### Android
- An update download that timed out on every source is tried once more through the engine, then directly.
