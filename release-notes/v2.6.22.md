## Shroudly 2.6.22

**Native clients and bots that ignore the proxy are noticed on networks that reset the connection too.**

### Programs around Shroudly, on networks that reset the handshake ([#48](https://github.com/umutxyp/Shroudly/issues/48))
- Some programs ignore Windows' proxy settings. Serein, a Discord client written in Rust, is one; bots and many command-line tools are others. Shroudly notices when such a program is stopped by the network and turns on Advanced mode by itself, which carries every program (since 2.6.16).
- The check looked at the program's connections. On a network that resets the handshake, a connection lasts a few milliseconds and leaves nothing to see, so Shroudly could miss the program entirely.
- Shroudly now also looks at the names that programs on this computer looked up themselves (Windows' DNS cache). A name like gateway.discord.gg stays there for minutes. When such a name is blocked on this network, Advanced mode is offered, with the program named when Shroudly can tell which one it is. Shroudly's own lookups do not count, and neither do Discord's own programs while Discord app mode is on.

Everything from [2.6.21](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.21) is included. Desktop users update automatically; the Android app tells you that 2.6.22 is out.
