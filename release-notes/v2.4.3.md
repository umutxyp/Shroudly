## Shroudly 2.4.3

### The Discord app now updates and opens through Shroudly
"Discord works in the browser but the app is stuck on *Checking for updates*" was the most common report. The cause: Discord's own updater runs before the app, ignores the system proxy, and on macOS and older Windows speaks only TLS 1.2, where the server's certificate travels unencrypted. A filter can read `discord.com` in the server's reply and cut it, whatever is done on your side — Advanced mode included.

**Discord app mode** (Windows and macOS) fixes it without admin rights. Shroudly runs a small relay on your own machine, points Discord's updater at it with one line in Discord's `settings.json`, and fetches each update from Discord over TLS 1.3. Updates arrive unchanged; Discord checks every package's SHA-256 itself.

- Offered once in the app while protection is on, and under **Settings → Discord app**. Never turned on without asking.
- The line is removed when you turn the mode off, when you quit Shroudly, and by the Windows uninstaller. An update endpoint you set yourself is never touched.
- If Discord is already open, Shroudly offers to restart it.

Thanks to **[Çağlar Sapmaz](https://github.com/caglarsapmaz)** for reporting the problem on macOS, confirming its TLS 1.2 cause and testing a fix on Türk Telekom.

### Harder networks: Iran, China, Russia and others
- **Encrypted DNS that is hard to block.** 17 routes from 6 operators instead of 3 fixed addresses: some by address with no name for a filter to read, some by name through the engine on addresses shared with millions of ordinary sites. Routes that fail rest and are retried; the one that works is remembered. Quad9 works for the first time (it only speaks HTTP/2).
- **Forged DNS answers refused.** About 180 block pages and sinkholes from 24 countries (from [OONI](https://github.com/ooni/blocking-fingerprints)) are recognised and refused.
- **"The site connects but the page stays blank."** Some filters let a connection start and then stop it. The engine now notices — a stall halfway through a record, a reset, a request never answered — and opens that site's next connection with another technique. You are told what is happening, and where only a VPN can help, Shroudly says so.
- **Advanced mode is always in Settings** on Windows and Linux. Before, it only appeared after a site test failed, so on networks where the test passed but pages stayed blank, it could not be found. On networks that filter like Iran's, China's or Russia's, it is also offered up front.
- **No more false "VPN running" warning.** A VPN now counts only while its tunnel is actually up. Cloudflare WARP installed but disconnected is no longer blamed; a connected one is named until you close it.
- **Port already in use?** If another program (v2rayN, Clash and others also use 10808) holds Shroudly's port, it moves to a free one, remembers it, and moves again if that one is taken too.

### Also since 2.4.1
- **Windows installer:** some first installs closed without installing anything. It was an old fault in the installer's folder lookup, present in 2.4.2 too. Fixed, and checked with 25 fresh installs each on Windows x64 and ARM.
- Encrypted DNS switches itself back on if a site cannot be opened with it off.
- The window explains why an app that was already open has to be restarted.
- Fixed: a site's learned technique was never updated once learned. GoodbyeDPI was reported as "GoodbyeDPI, ByeDPI".
- `.rpm` packages now depend on libraries rather than Fedora package names, so they install on openSUSE and RHEL-family systems too.
- New in every language: all of the above, in all 15.

### Tested before release
Every package is installed on its own system before this release is published: `.pacman` on Arch, `.rpm` on Fedora and openSUSE, `.deb` on Debian and Ubuntu 22.04/24.04, both AppImages, the Windows installer and uninstaller (x64 and ARM), and both macOS disk images. Network tests run on Windows, Linux and macOS, x64 and ARM, and the engine again under AddressSanitizer.

Everything from [2.4.2](https://github.com/umutxyp/Shroudly/releases/tag/v2.4.2) is included. Users of 2.0.4 and later update automatically.
