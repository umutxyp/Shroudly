## Shroudly 2.5.13

More for computers that share one network (internet cafes, classrooms, offices) and for anyone using Advanced mode. Every change below was tested on real Windows (x64 and ARM), macOS and Linux machines, including Advanced mode's packet driver on Windows and a lab network with a filter on Linux.

- **Advanced mode leaves your local network alone.** It no longer changes or adds packets for anything on the local network: the router, other computers, consoles and printers nearby. A connection reset is only stopped when it comes from a server Shroudly itself was helping; every other one passes as it should.
- **Games and apps mode leaves nothing behind on Windows.** The setting that points programs at Shroudly now lives only in the current Windows session, so it is gone after you sign out or restart, can never end up in a disk image, and no longer reaches programs started at the next sign-in. Settings left by older versions are cleaned up.
- **No connection storms.** When a server simply does not answer (often a game's or app's background service), Shroudly no longer opens more and more extra connections to it: there is a limit across the whole computer, and such a server is tried more gently for a minute. Encrypted DNS also asks its servers a few at a time instead of all at once when the line is slow.

Everything from [2.5.12](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.12) is included. Users of 2.0.4 and later update automatically.
