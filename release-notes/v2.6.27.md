## Shroudly 2.6.27

**Windows and Linux no longer get a macOS message when Discord's settings cannot be changed.**

### The right reason, on the right system
- When Shroudly could not write Discord's settings, it said the same thing everywhere: that macOS had to allow Shroudly to change Discord's settings. A Windows 11 user was shown exactly that and could do nothing with it.
- On macOS that message is right — the system really does ask for permission, and Shroudly offers the prompt. On Windows and Linux the same refusal means something else: the file is in use (Discord still running) or write-protected.
- Shroudly now says that instead, with the step that actually helps: close Discord completely, including from the system tray, and try again. It is written to the log too.

Everything from [2.6.26](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.26) is included. Desktop users update automatically; the Android app tells you that 2.6.27 is out.
