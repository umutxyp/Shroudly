## Shroudly 2.4.4

- **Linux, Advanced mode:** when the library Advanced mode needs is missing, the app now shows the install command for your distribution — `pacman` on Arch, `dnf` on Fedora and RHEL, `zypper` on openSUSE, `apt` on Debian and Ubuntu — instead of always the Debian one. Each command is run on its distribution before release.
- The Windows update feed no longer lists an installer that is not published. (Updates were not affected: the updater always picks the file for your processor.)

Everything from [2.4.3](https://github.com/umutxyp/Shroudly/releases/tag/v2.4.3) is included — Discord app mode, encrypted DNS that is hard to block, help on networks like Iran's and Russia's, and the Windows installer fix. Users of 2.0.4 and later update automatically.
