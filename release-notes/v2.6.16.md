## Shroudly 2.6.16

**A bot or tool that goes around Shroudly now gets Advanced mode by itself, and a slow network DNS no longer makes a site give up.**

### Programs that go around Shroudly: Advanced mode by itself (Windows, Linux)
- Some programs never use the system proxy: a Discord bot on Node.js or Python, a command-line tool, a game's launcher. On a network that blocks what they reach, they kept failing while the browser worked, until Advanced mode was turned on by hand.
- Shroudly now notices such a program by itself. It sees one connect to a block page that the network's DNS sent it to, or connect straight to a service or site found blocked on this network. It then turns on Advanced mode, which carries every program, and says which program it was for in one line. Windows or Linux asks for permission as usual. If you decline, Shroudly does not ask again by itself for two weeks. It never asks while a game's anti-cheat is running.
- Shroudly's own processes never count, and neither do apps that a mode already carries (Discord with Discord app mode on, Roblox with Games and apps mode on). It looks only on networks that show a filter. Elsewhere it does not read the connection table at all.

### Your network's own DNS, given time ([#43](https://github.com/umutxyp/Shroudly/issues/43))
- When no address from encrypted DNS answers, Shroudly also asks the network's DNS (since 2.6.13). A slow network DNS that took longer than a second and a half made Shroudly give up on the site for half an hour, without a word in the log. It now waits up to five seconds. If there is still no answer, it asks again on the next connection.
- When the network's DNS gives the same addresses as encrypted DNS, the log now says so in one line, instead of saying nothing.

Everything from [2.6.15](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.15) is included. Desktop users update automatically; the Android app tells you that 2.6.16 is out.
