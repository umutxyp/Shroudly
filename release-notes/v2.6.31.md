## Shroudly 2.6.31

**Updates keep arriving even where GitHub itself is blocked.**

### Auto-update with a fallback server
- Some networks block GitHub's addresses outright. Shroudly works on your device and cannot reach an address that is blackholed, so the updater could never see a new version there.
- The updater already tried a direct connection and then the system proxy. If both fail, it now also tries Shroudly's own download server (`shroudly.codeshare.me`), which serves the same release files. Nothing changes for anyone who can reach GitHub.
- Works on Windows, macOS and Linux. The files are the same ones published here, and the installer is still checked against the release's checksum before it is used.

Everything from [2.6.30](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.30) is included. Desktop users update automatically; the Android app tells you that 2.6.31 is out.
