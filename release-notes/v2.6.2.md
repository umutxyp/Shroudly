## Shroudly 2.6.2

**Fixes for what you reported: Android cutting other apps' internet, Discord, Xbox, the system proxy and internet cafes.**

### Android
- **Other apps no longer lose their internet when protection is on.** The engine now runs inside the app itself, so the phone's battery manager can no longer stop it behind the app's back. On networks with IPv6 (most mobile networks), the connection is no longer rebuilt a few seconds after you turn protection on, which cut every app's connections.
- **Never a phone without internet.** If the way through stops working, Shroudly restarts it once; if it still does not work, protection ends and tells you, so your apps connect directly again. A network that is simply down is no longer mistaken for a problem of Shroudly's. With Android's "Block connections without VPN" on, protection stays on and keeps trying instead.
- **Wi-Fi stays Wi-Fi:** the phone no longer treats Wi-Fi as mobile data while protection is on, and the Wi-Fi icon stays where it was.
- **Private DNS** keeps working after the connection is renewed.
- **"Share logs"** under About, to send a report when something does not work. It is only sent if you choose to share it.
- The phone is now counted in the live total, the same way as a computer, and only while protection is on. Turn it off under About → **Count me in the live total**.

### Discord
- **Voice and the app on networks that block Discord:** when the Discord app hangs on "Starting" or a call stays on "RTC Connecting", Shroudly turns on Advanced mode by itself, since the sound of a call goes over UDP. Advanced mode now touches only what a call needs (its voice servers' first packets), nothing else.
- Opening Discord no longer brings up a permission prompt when no call is starting.

### System proxy
- **When another program takes the system proxy, Shroudly sets it back by itself** within seconds, with one line in the log, so you no longer have to press "Set Shroudly again". If a program keeps taking it back at once, Shroudly stops and names that program.
- Pressing Stop never leaves a proxy that no longer works behind: when the setting you had before points at a program that has since closed, it is not put back.
- **Encrypted DNS:** a one-second blip on the network is no longer reported as "Encrypted DNS is not reachable", and an answer that arrives late is still used, so sites open instead of failing in bursts.

### Xbox and Microsoft Store apps
- **The Xbox app, Microsoft Store and other Store apps and games can sign in and load again.** Windows keeps these apps from reaching programs on the same computer, Shroudly included, unless they are given an exemption. Shroudly now adds it with one permission prompt, only when such an app is actually open, and only for accounts that can say Yes. It removes only what it added when you turn it off or uninstall Shroudly.

### Internet cafes and slow computers
- **A Roblox installer started by a script is caught in about 6 seconds instead of a minute** and started again through Shroudly, also on slow, ARM and freshly started computers and where PowerShell is restricted. Nothing is ever closed unless it can be started again, and a game in progress is left alone after Shroudly updates.

Everything from [2.6.1](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.1) is included. Desktop users update automatically; the Android app tells you that 2.6.2 is out.
