## Shroudly 2.6.35

**VALORANT and League of Legends start again next to Shroudly (#56).**

### Riot Vanguard and Advanced mode
- Riot's anti-cheat, Vanguard, can refuse VALORANT and League while a packet driver like the one Advanced mode uses is loaded. Two things let that happen:
  - Advanced mode stepped aside only once the game's own program started. But the sign-in and Vanguard's check happen earlier, in the Riot Client. Now, on a PC with Vanguard, Advanced mode also steps aside while the Riot Client or League's client is open, and never turns itself on then.
  - When Advanced mode stopped, its driver (WinDivert) stayed loaded until a restart, so the game could still be refused after Shroudly was closed. Now it is unloaded whenever Advanced mode stops. If another program that uses the same driver is running (GoodbyeDPI, zapret), it is left alone so that program keeps working.
- If VALORANT still refuses to start right after the update, restart the computer once.

Everything from [2.6.34](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.34) is included. Desktop users update automatically; the Android app tells you that 2.6.35 is out.
