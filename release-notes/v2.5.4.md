## Shroudly 2.5.4

- **Only in the menu bar while it works in the background (macOS).** With its window closed Shroudly no longer keeps an icon in the Dock; it stays in the menu bar, like other menu bar tools. Opening it from the menu bar, Spotlight or Launchpad brings the Dock icon back together with the window. Thanks for the suggestion in [#9](https://github.com/umutxyp/Shroudly/issues/9).
- **The same on Windows and Linux:** with the window closed there is nothing in the taskbar, only the tray icon. Now checked on every system by the automated tests.

Everything from [2.5.3](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.3) is included. Users of 2.0.4 and later update automatically.
