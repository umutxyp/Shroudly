## Shroudly 2.6.24

**Advanced mode can split the TLS record itself, for networks that reassemble the connection before they inspect it ([#48](https://github.com/umutxyp/Shroudly/issues/48)).**

### Programs that ignore the proxy, on networks that read whole connections
- Advanced mode carries every program at the packet level, whatever its network stack: a native client, a bot, a game launcher. Until now it split the first packets of a connection. Some networks (Türkiye's Superonline, for one) put the TCP stream back together before they look, then match the server name inside a single TLS record, so splitting the packets does not get past them — only splitting the TLS record does, which is what Shroudly's proxy already does for the programs that use it.
- Advanced mode can now do the same at the packet layer: it splits the ClientHello into two TLS records so the name never sits whole in one, and keeps the connection's sequence numbers in step as it grows. This carries the programs that bypass the proxy (Serein and other native clients, bots, launchers) past such a network too.
- It is **off by default** and does more work per connection, so it is turned on only when a network needs it. This release is the groundwork; a reporter on Superonline is confirming it before it is enabled automatically.

Everything from [2.6.23](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.23) is included. Desktop users update automatically; the Android app tells you that 2.6.24 is out.
