## Shroudly 2.5.14

- **Shroudly tells you when a browser goes around it.** If a site opens in one browser but not in another, the other usually has a proxy or VPN setting of its own, or an extension, in the way. Shroudly now notices a browser that talks to the internet without going through it and names it in one line, so you know where to look.
- **Firefox set back to the system proxy.** If Firefox was set to "No proxy" or "Auto-detect proxy settings", it never went through Shroudly. Shroudly now puts it back to "Use system proxy settings" while Firefox is closed (once; if you choose otherwise later, that is kept). A proxy you entered yourself is never changed.

Everything from [2.5.13](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.13) is included. Users of 2.0.4 and later update automatically.
