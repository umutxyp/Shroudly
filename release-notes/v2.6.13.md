## Shroudly 2.6.13

**YouTube and other big sites can now open from their caches inside your country, and programs that ignore the proxy get Shroudly's settings and encrypted DNS more reliably on Windows.**

### A site's cache inside the country ([#37](https://github.com/umutxyp/Shroudly/issues/37))
- In some countries a site's servers abroad are blocked by address, or filtered past every technique, while its cache inside the country is open. YouTube's videos in Iran are an example: they come from Google's caches in Iranian networks. Your network's own DNS gives the cache's address; encrypted DNS gives one abroad.
- Now, when every technique fails at the addresses encrypted DNS gives (or none of them answers), Shroudly also asks your network's DNS. If that gives a different public address, Shroudly tries it, and keeps using it for that site while it works. The log says so in one line.
- Your network's DNS only learns about a site that is failing anyway. It is never used when you chose **Only this server** in DNS settings, and a private or block-page address is never followed.

### Programs that ignore the proxy
- **Windows:** when a mode sets the proxy for programs (`HTTPS_PROXY`), Shroudly now tells Explorer about it directly. Before, it did this only through PowerShell, which some security products or policies stop. When that happened, programs opened from the Start menu, the taskbar or Win+R did not get the setting ([#33](https://github.com/umutxyp/Shroudly/issues/33): "Environment variable HTTPS_PROXY not defined").
- **Advanced mode:** when it starts answering other programs' DNS with encrypted DNS, it now first empties the system's DNS cache. Forged answers the network gave earlier were otherwise handed to programs from that cache, without a question the encrypted DNS could answer. This affected Discord tools and bots that failed with `CERTIFICATE_VERIFY_FAILED`.

Everything from [2.6.12](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.12) is included. Desktop users update automatically; the Android app tells you that 2.6.13 is out.
