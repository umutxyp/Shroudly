## Shroudly 2.6.36

**Updates install into the folder Shroudly actually runs from (#57).**

### Windows: no more second copy after an update
- If Shroudly was installed somewhere other than the default folder (another disk, for example), an update could be installed into the default folder instead. You then had two copies, and the one you start stayed on the old version.
- The installer goes by its own records of where Shroudly is installed, and those can point elsewhere: after installing once to the default folder and again to another disk, or once "for me only" and once "for everyone".
- Now the updater tells the installer exactly where the running copy is, and the update goes there. Tested on Windows x64 and ARM64 with the installer's records pointing at the default folder: the update still went to the copy's own folder.
- A copy under Program Files, which only an administrator can change, is updated as before.

Everything from [2.6.35](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.35) is included. Desktop users update automatically; the Android app tells you that 2.6.36 is out.
