## Shroudly 2.6.23

**Android: protection comes back after the lock screen in Proxy only too, and the Quick Settings tile shows the right state on every phone.**

### Back on after unlocking, in Proxy only ([#39](https://github.com/umutxyp/Shroudly/issues/39))
- Some phones turn Wi-Fi and mobile data off while the screen is locked, and close apps at the same moment. Since 2.6.12, Shroudly asks Android to bring protection back as soon as a network is there again, but only in VPN mode.
- Proxy only is the mode for people who keep another VPN app. It now does the same: when the last network goes away, or Android closes Shroudly while it is on, protection comes back by itself with the network. If you turned it off yourself, it stays off.
- If Android does not let Shroudly start in the background, a notification turns it on with one tap. Letting Shroudly run without battery restrictions avoids that.

### The Quick Settings tile ([#49](https://github.com/umutxyp/Shroudly/issues/49))
- On some phones (HyperOS, for example), the tile was blue when protection was off and grey when it was on.
- The tile is now a plain on/off switch, and the panel asks Shroudly for the state every time it opens. While protection is starting or stopping, the tile already shows where it is going, with "Starting…" or "Stopping…" under it.

Everything from [2.6.22](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.22) is included. Desktop users update automatically; the Android app tells you that 2.6.23 is out.
