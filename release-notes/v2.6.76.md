## Shroudly 2.6.76

**A 32-bit Shroudly on a 64-bit Windows moves to the 64-bit one; sharing finds a free port; the icon choice on Android shows every icon.**

### Desktop
- Windows: a 32-bit Shroudly installed on a 64-bit Windows kept updating to the 32-bit installer, where Advanced mode cannot run (#86). The update now installs the 64-bit one over it; settings stay. A real 32-bit Windows and Windows on ARM are not touched.
- Sharing this connection: Windows (Hyper-V, WSL) keeps ranges of ports for itself, and they move at each start. When the port Sharing had was in one of them, Sharing did not start; it now takes another port and keeps it.

### Android
- Settings > Appearance: every icon in the choice looked like the classic one (the Play and GitHub builds left out the pictures the list looks up), although tapping one changed the home-screen icon correctly. Each icon shows its own picture again.
