## Shroudly 2.6.10

**Your own DNS server is now the only one asked about names whose DNSSEC check fails, and a new option, "Only this server", keeps every lookup on it.**

### Your own DNS server ([#34](https://github.com/umutxyp/Shroudly/issues/34))
- **Fixed:** a "server failure" (SERVFAIL) answer is final now. A DNSSEC-checking server gives this answer when a name's signatures are wrong; DNSSEC tests rely on it. Shroudly treated it as no answer: it waited 4 seconds and then asked public plain DNS (Cloudflare, Google, Quad9, Cisco) and your network's DNS. Some of those do not check signatures, so a forged answer was accepted. DNS test sites then listed those resolvers next to yours and showed DNSSEC as failed. Now the answer goes back at once and nobody else is asked. This applies to your own server and to Shroudly's built-in encrypted DNS. For the built-in DNS, two different providers must give the same failure, so one provider's passing problem does not break a site.
- **New: Only this server.** Tick it under Settings → DNS server (desktop and Android) and nothing else is ever asked: not the built-in encrypted DNS, not plain DNS, not your system's DNS. If the server does not answer, lookups fail until it does, and the log says why in one line. Use it to test a server, or when no one else may see your lookups. Without it, the built-in encrypted DNS still answers while your server is down, as before.
- Ticking or unticking it for the server already in use applies at once; nothing restarts.

Everything from [2.6.9](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.9) is included. Desktop users update automatically; the Android app tells you that 2.6.10 is out.
