## Shroudly 2.6.47

**On iPhone and iPad too, with your own server; help people in censored countries; get through networks that let only allowed sites through; and keep up to date where GitHub is blocked.**

### iPhone and iPad
- **The app for iPhone and iPad** (and Mac, from the same build) is on this page as an `.ipa`, until the App Store has it: install it with **TrollStore**, or sign it with your own Apple developer account (AltStore, SideStore, Sideloadly…). It works as a VPN on the device, with the same engine and encrypted DNS as the desktop and Android.
- **Your own server** (Settings): every site through a `socks5://`, `http://` or Shadowsocks `ss://` link, as on the desktop and Android; the link's password is not shown. If the server stops working, the main screen says so and why.
- **"Only this country's network works"**: in a shutdown, said in so many words, with the guide in your language.

### Help people in censored countries
- **On a computer** (Settings → More settings; off until you turn it on): Shroudly runs a **Snowflake proxy** for the Tor network, so people where Tor is blocked reach it through your connection. They are strangers using Tor: what they open stays encrypted, and they cannot reach your computer or your network. It uses some of your connection while someone is helped, keeps no record, and shows how many it is helping. It runs in a hidden, sandboxed window of its own that can reach only Tor's servers.
- **On Android** (About) and **iPhone/iPad** (About): the apps made for it, which keep running on their own: Psiphon's **Conduit**, and on Android also **Orbot's Kindness Mode** (Tor).

### Shutdowns that keep only allowed sites
- **Decoys carry names the network allows.** Some shutdowns let through only a list of allowed sites, judged by the first message of each connection. Shroudly's decoys (Advanced mode on Windows and Linux, and the default engine on Linux) now carry the name of a large site of your own country instead of a scrambled one: the country a shutdown showed, or your system's time zone. A filter that blocks a list of sites is fooled as before; a filter that allows only a list now lets the real connection through. Checked on a real packet path against such a filter.

### Where GitHub is blocked
- **The desktop's site list and ad list come through a CDN front** when GitHub does not answer: GitHub's files are served by Fastly, which still hands them over on a connection opened to another of its sites (python.org, pypi.org, fastly.com, ted.com), that site's certificate checked. What arrives is checked as before. (Google, Cloudflare, Akamai, CloudFront and Azure no longer allow this, so nothing else is fronted; and no browser traffic is ever touched this way.)

### Also
- Tests: the Snowflake proxy end to end on every OS (a person using Tor reaching the relay over real WebRTC), the whitelist filter on a real packet path, Shadowsocks on iPhone/iPad/Mac against the same vectors as the desktop, Android and shadowsocks-libev, the `.ipa` checked in CI, and the CDN fronts against the real CDN.
- New text in all 31 languages.

Everything from [2.6.46](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.46) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.47 itself.
