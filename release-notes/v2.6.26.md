## Shroudly 2.6.26

**Linux: Games and apps mode now reaches Flatpak programs — Roblox through Sober, Discord, Steam.**

### Flatpak programs go through Shroudly
- A Flatpak program runs in a sandbox and is never handed the desktop's environment, so a proxy set for the session never reached it. On Linux that meant Games and apps mode had nothing to offer at all: Roblox through Sober went straight out, around Shroudly, whatever the settings said. (A user found this and worked around it by starting Sober from a terminal with the proxy spelled out by hand — which works, but not from the program's own icon.)
- Flatpak has one supported place for it, an override it reads at every start, icon or terminal alike. Shroudly now writes one for each Flatpak program it covers that you actually have installed: Sober and Vinegar (Roblox), Discord, Vesktop, WebCord and Steam. It is never a machine-wide override, only those programs.
- A program that already has a proxy of its own is left exactly as it is.
- The setting is taken out again when the mode goes off and when Shroudly quits, and removal is checked: on an older Flatpak that does not understand removing a value, Shroudly empties it instead, which programs read as no proxy — so nothing is ever left pointing at a proxy that is gone.

Everything from [2.6.25](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.25) is included. Desktop users update automatically; the Android app tells you that 2.6.26 is out.
