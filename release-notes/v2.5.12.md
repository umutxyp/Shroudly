## Shroudly 2.5.12

Fixes for shared and frozen computers (internet cafes, classrooms, offices: many PCs from one disk image, often reset at every start) and for the Discord app.

- **Roblox installers start without waiting.** When a script or a launcher starts Roblox's installer before Shroudly has set things up (a game disk on a shared PC), Shroudly now starts that same installer again through itself, after checking it is signed by Roblox, instead of downloading a new one. An installer that was already open when Games and apps mode came on is handled at once.
- **Nothing left behind when Shroudly is closed by force.** If other software ends Shroudly without warning, the settings it made for programs are removed at the next start in every case (also when its own records are gone, or the disk image was made while it ran), and the one that breaks programs outright is removed first. Its small guard process is started again if it is stopped, and on Windows its cleanup is not ended together with a closing session.
- **Discord app stays reachable.** While Discord app mode is on, the line Discord needs is put back within seconds if it goes missing (for example when Discord rewrites its settings as it closes), and Discord's update requests get a second try on a new connection, so a missing line or one dropped connection no longer leaves Discord on "Update failed". At logout the line stays only if Shroudly starts with Windows; otherwise Discord opens normally without it.
- **Games with anti-cheat.** Advanced mode is no longer started by itself while a game's anti-cheat (Vanguard, Easy Anti-Cheat, BattlEye, FACEIT and similar) is running. You can still turn it on yourself.
- **Faster where public DNS is blocked.** On networks that only let their own DNS through, Shroudly stops waiting for public DNS servers that never answer, so new sites open seconds sooner.
- **Updates spread out.** Computers started together no longer all check for and download an update at the same moment.

Everything from [2.5.11](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.11) and [2.5.10](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.10) is included. Users of 2.0.4 and later update automatically.
