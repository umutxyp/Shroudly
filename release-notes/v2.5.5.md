## Shroudly 2.5.5

- **Roblox through Shroudly, installer included (Windows).** With Games and apps mode on, Settings now has **Open Roblox** and **Install Roblox**. Install downloads Roblox's own installer through Shroudly, checks that it is signed by Roblox Corporation and starts it; before, the installer stopped at *Continue installation without flag settings*. Bloxstrap and Fishstrap are started the same way.
- **Roblox no longer slips past Shroudly unnoticed.** Roblox started from a browser that was already open kept that browser's old settings and connected directly, so it stayed blocked. Shroudly now notices within half a minute and offers to restart it through Shroudly.
- **Blocked sites stay on Shroudly.** When one connection to Shroudly failed, browsers used to go around it for five minutes, and blocked sites failed with no sign of why. Listed sites now always go through Shroudly.
- **Networks that drop connections instead of refusing them.** Some providers do not reset a blocked connection, they simply never answer. Shroudly now keeps trying the other techniques there and remembers how far it got, so the next connection starts where the last one stopped. A site that answers nothing at all is reported in Logs, without a notification, since a site that is down looks exactly the same.
- **Connections cut while being sent.** On some networks the filter cuts a connection while Shroudly is still sending it. Shroudly gave up on that connection, so apps kept reconnecting and pages loaded half-way; it now moves on to the next technique.
- **One site, one lesson.** What works for a site is now used for all of its addresses at once (www., api., cdn. and the rest), instead of being found again for each one, so the parts of a site after the first open without the extra wait.
- **macOS: Standard (non-administrator) accounts.** macOS does not let them change network settings, so nothing went through Shroudly. The window now says so and asks for an administrator's password once; stopping needs no password.
- **Linux: KDE Plasma, XFCE and LXQt.** KDE's own proxy setting is set. On XFCE and LXQt, which have no system proxy setting, Firefox goes through Shroudly at once and Chrome, Edge, Brave and other Chromium browsers after you log out and back in.
- **Told when another program takes over.** If a VPN or another proxy program changes the system proxy while Shroudly is on, the window says so, with a button to set Shroudly again.
- **A site that refuses you itself is explained.** Some services turn whole countries away on their own (a block page, or silence after connecting). Shroudly never changes your address, so it cannot help there; the site test and the window now say so instead of suggesting another technique. This is judged from what the site does, the same way in every country.
- **Every address of a site is tried.** When a site has several servers and one does not answer, the next one is used.
- **Updates wait for your game.** An update no longer restarts Shroudly while Roblox or Discord is running; it installs once they are closed, or when Shroudly quits.
- **Linux desktops without a tray:** closing the window minimises it instead of leaving Shroudly running with no way back, and Settings has a Quit button.
- Smaller things: programs that only speak SOCKS4 are served; Logs names the program that answers DNS on this computer, and says when the system DNS answers nothing; a site that could not be reached at all is logged once with the reason.

Everything from [2.5.4](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.4) is included. Users of 2.0.4 and later update automatically.
