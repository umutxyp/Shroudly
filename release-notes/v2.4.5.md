## Shroudly 2.4.5

- **Site test works again.** Since 2.4.1, *Settings → Test a site* never showed a result: the button kept spinning until it gave up, and the log said "undefined" where the site's name belonged. The engine was writing the site's name under the wrong field. Fixed, the name is now always written safely whatever is typed, and a test guards it.

Everything from [2.4.4](https://github.com/umutxyp/Shroudly/releases/tag/v2.4.4) is included. Users of 2.0.4 and later update automatically.
