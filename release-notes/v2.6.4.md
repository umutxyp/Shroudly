## Shroudly 2.6.4

**An ad and tracker blocker, Android settings and a proxy-only mode, Roblox Studio from the website, and the system proxy no longer lost when Shroudly is opened twice.**

### Block ads and trackers (desktop and Android)
- **New, off by default:** turn on **Block ads and trackers** (desktop Settings, Android About). Names on a public ad and tracker list ([StevenBlack/hosts](https://github.com/StevenBlack/hosts)) get no answer, in every app; nothing is fetched for them.
- The list is downloaded through Shroudly, checked before it is used and refreshed weekly. Sites you never want blocked can be listed as exceptions.
- The number of blocked lookups is shown with the stats. Nothing about blocked names is logged or sent.

### Android
- **Settings** (About → Settings): the accent colour (the desktop's colours), the bypass technique (automatic by default), **apps that skip Shroudly** (their traffic goes straight out, e.g. a game), and **start when the phone starts**.
- **Automation apps** (Settings, [#32](https://github.com/umutxyp/Shroudly/issues/32), off by default): Tasker, MacroDroid and similar apps can turn protection on and off, for example on when a game opens and off when it closes. Send a broadcast to `me.codeshare.shroudly` with the action `me.codeshare.shroudly.action.START`, `STOP` or `TOGGLE`. If Android does not let it start from the background, a notification turns it on with one tap.
- **Proxy only** (Settings → Mode, [#31](https://github.com/umutxyp/Shroudly/issues/31)): instead of the VPN, Shroudly runs as a proxy on `127.0.0.1:10808` (SOCKS5 and HTTP), so **another VPN app can stay connected**. Apps set to use it go through Shroudly: the Wi-Fi network's proxy (host `127.0.0.1`, port `10808`) or an app's own proxy setting. No VPN permission is asked for.

### Roblox Studio and programs that ignore the system proxy
- **Roblox Studio opened from the website's Edit button now goes through Shroudly** ([#30](https://github.com/umutxyp/Shroudly/issues/30)), and Shroudly no longer asks you again and again to reopen it. While Games and apps mode is on, Roblox's links (also through Bloxstrap-style launchers) open their program through Shroudly; everything is put back as it was when the mode is turned off, Shroudly quits or is uninstalled.
- **Bots and command-line tools:** on a network that forges DNS answers, Games and apps mode now turns on by itself (Windows, macOS), so programs that never read the system proxy go through Shroudly too, **Node.js** ones included. Restart the ones that were already open. A proxy you set yourself is never replaced.

### The system proxy, Discord and Advanced mode
- **Opening Shroudly again while it runs** (its icon, a shortcut, the Start menu) no longer removes its system proxy a few seconds later. This was the cause of "the proxy is gone after Discord starts": the second copy put things back as if Shroudly had quit. It now just brings the open window to the front.
- Discord is asked to restart only when it really started without Shroudly's setting.
- **Advanced mode turns on by itself again on PCs with an anti-cheat installed.** Riot Vanguard, Easy Anti-Cheat, BattlEye, FACEIT and the like leave a service running all the time; only a game actually being played now keeps Advanced mode waiting.

### Logs
- **Copy logs** now puts a short version on the clipboard that fits in one chat message (the newest lines, repeats folded).
- **Save logs** (Logs panel and tray) writes the whole log to a text file in your Downloads folder, for when it is too long to paste.

Everything from [2.6.3](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.3) is included. Desktop users update automatically; the Android app tells you that 2.6.4 is out.
