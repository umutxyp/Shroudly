## Shroudly 2.6.53

**When a site turns you away because of where you are, Shroudly says what does change it.**

### Computers
- Some sites refuse visitors from certain countries themselves (for example because of sanctions). No technique changes that, and Shroudly already said so. Now it also says what does: someone you trust in another country turns on **Share my connection** in Shroudly on their computer and sends you the link, and you paste it in **Your own server** (Settings → Server and sharing). Sites then see their country instead of yours. Shown in the notice and in the site test in Settings, and not while your own server is already in use.

### Phones, tablets and TVs
- Nothing changes on Android or on the App Store app; this release keeps the stores on the same version as GitHub.

Everything from [2.6.52](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.52) is included. Desktop users update automatically; the Android app from GitHub offers to install 2.6.53 itself.
