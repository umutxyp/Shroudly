## Shroudly 2.6.32

**The Android app finds its updates even where GitHub itself is blocked.**

### Android update check with a fallback server
- 2.6.31 gave the desktop updater a second source: where a network blocks GitHub's addresses outright, it gets the same release files from Shroudly's own download server (`shroudly.codeshare.me`).
- The Android app now does the same. If GitHub cannot be reached, its update check asks that server for the latest version, and the **Update** button opens the APK from there. Android still asks before installing it, as always.
- Nothing changes where GitHub can be reached. Copies installed from Google Play keep updating through Play.

Everything from [2.6.31](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.31) is included. Desktop users update automatically; the Android app tells you that 2.6.32 is out.
