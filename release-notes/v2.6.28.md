## Shroudly 2.6.28

**Discord app mode now changes Discord's settings even when the file is read-only or held open, and says exactly why when it still can't.**

### Writing Discord's settings, reliably
- On Windows, writing Discord's settings could fail even after closing Discord: the file may carry the read-only attribute, and replacing a file another process still holds open is refused. Shroudly showed "could not be written" and the retry seemed to do nothing.
- Shroudly now clears a read-only attribute first and, when it cannot replace the file, writes the change in place — so the usual cases just work.
- When it genuinely cannot write (Discord is still running, or a security product is guarding the folder), it says which it is and what to do: quit Discord from the system tray too, or allow Shroudly through Windows' Controlled folder access.

Everything from [2.6.27](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.27) is included. Desktop users update automatically; the Android app tells you that 2.6.28 is out.
