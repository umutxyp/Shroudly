## Shroudly 2.6.29

**Advanced mode now splits the TLS record by itself — the technique that gets through networks like Superonline, with nothing to turn on.**

### The stronger technique, on by default
- Some networks put the whole connection back together before they inspect it, then match the server name inside a single TLS record. Splitting the packets does not fool them; splitting the TLS record does (issue [#48](https://github.com/umutxyp/Shroudly/issues/48), confirmed on real Superonline). It carries programs that ignore the proxy — native clients, bots, launchers — through such a network too.
- Since 2.6.24 this existed as a setting; now Advanced mode turns it on by itself, because it is the technique that actually works on these networks and is the stronger one (it does what the plain cut does and more). Nothing to find, nothing to edit.
- It costs a little more per connection; anyone who wants the lighter path can still turn it off.
- Note: Advanced mode shapes a connection from its first packet, so if a program was already connecting when Advanced mode turned on, let it reconnect (or restart it) to be covered.

Everything from [2.6.28](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.28) is included. Desktop users update automatically; the Android app tells you that 2.6.29 is out.
