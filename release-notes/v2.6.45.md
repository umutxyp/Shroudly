## Shroudly 2.6.45

**A large round of fixes from a full review of every platform: protection that keeps itself on, plain answers when a network is the problem, and an Android APK that updates itself.**

### The window
- **Settings are simpler.** What most people need comes first: language, testing a site, apps, the application and its look. Everything else is under **More settings**, which opens by itself when something in it was changed.
- **One list for the technique, as on Android.** "Auto (recommended)" is Auto mode; choosing a fixed technique turns it off.
- **Testing a site gives one plain answer,** with a single Advanced mode button where it helps and a way to start protection from there.
- **"Starting…" while protection comes up,** and a start that failed is shown under the status with a **Repair** button.
- **Banners:** the proxy comes first, every banner can be closed unless something is still broken, and each has the button its words promise (Try again, Clear it, Copy address, Save logs).
- **Closing the window quits Shroudly** when "Keep running in the tray" is off, as the switch says.
- **Ads blocked are counted on the desktop too.** About explains what Shroudly does in plain words, once.
- **A damaged install says so in your language,** with a button to download Shroudly again.

### All computers
- **Protection you left on comes back by itself.** If it stops (a crash, a network that was down), Shroudly starts it again after a short pause, and at once after sleep or a network change. It tells you the first time.
- **A network with no internet is called that,** not "Protected" with a browser error that seems to blame Shroudly. On a network that lets nothing out except its own proxy, Shroudly says so and that Stop puts things back.
- **Sites blocked by their address are explained in the window,** for any site, not only Discord and Roblox.
- **Plain-HTTP block pages are recognised,** so Shroudly tries its HTTP techniques instead of taking the block page for the site.
- **Encrypted DNS also works over IPv6,** for networks that offer nothing else.
- **A settings file that cannot be written, or an unexpected error, no longer stops Shroudly.**
- **Updates never restart Shroudly while you are using the computer,** and an installer that cannot start no longer closes it.
- **More VPN programs are recognised** when they get in the way (Windscribe, Mullvad, Urban VPN, Hotspot Shield, PIA, CyberGhost, TunnelBear, AdGuard VPN, Cisco, GlobalProtect, FortiClient, Ivanti and Zscaler).
- **The window is easier to read:** high-contrast themes, tall scripts (Burmese, Thai, Amharic), the current tab and keyboard focus are clearer; right-to-left notifications are laid out correctly.
- **Every language is complete:** nothing is left in English, and the logs are in your language too.

### Windows
- **Shroudly survives "End process tree".** If Shroudly is ended together with everything it started (Task Manager's "End process tree", or a café's reset script), your proxy settings are still put back within a second.
- **Computers whose proxy is set by an administrator** (schools, offices, cafés using Group Policy) now say so plainly instead of showing "Protected", and offer Advanced mode, which works beneath those settings.
- **The tray icon can be seen on a dark taskbar.**
- **Two people signed in at once:** one person's Discord, browsers and programs are no longer mistaken for the other's.
- **"Start at sign-in" turned off in Task Manager stays off.**
- **A standard account is never shown an administrator prompt for Advanced mode by itself.**
- **The installer asks no questions on a new install.**

### macOS
- **A new Liquid Glass icon,** made from Shroudly's shield.
- **The menu bar and the window title are in your language.**
- **A copy run from the disk image or Downloads offers to move itself to Applications.**
- **Updates on a standard account need one administrator password,** and the updated app opens in the background.
- **No "Background Items Added" notice at every Start.**
- **A network connection added after Start** (an iPhone over USB, a new adapter) gets Shroudly's setting too.
- **A full-screen game or video is never interrupted** by Shroudly's own actions.

### Linux
- **Advanced mode's password window names Shroudly and says why,** in your language (deb, rpm and pacman). The AppImage no longer runs its helper from /tmp.
- **The tray icon can be seen on a dark panel,** and polkit's answers are told apart (a closed window, no password agent).

### Android
- **The APK from GitHub updates itself:** it tells you once when a new version is out, downloads it when you tap **Download and install**, checks that it is signed by Shroudly, and Android's installer asks you to confirm.
- **Protection is back on after a phone restart,** in VPN mode too.
- **Network changes no longer cut every app's connection twice,** and a network coming or going during a check is no longer taken for a broken one.
- **Proxy only:** your own DNS server is reached through the proxy you set for it.
- **Share logs** says who to send them to and can leave the site names out.
- **Settings are simpler,** the main screen says what is true and what to do, and the battery notice says where to tap.

Everything from [2.6.44](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.44) is included. Desktop users update automatically; the Android app from GitHub now offers to install 2.6.45 itself.
