## Shroudly 2.5.9

- **Advanced mode: the real handshake is cut too.** Advanced mode sends a decoy first and then the real first packet. That packet used to go out whole, so a filter the decoy does not fool still read the site's name in it. Programs that ignore the proxy and reach the internet on their own (Lampcord, [#11](https://github.com/umutxyp/Shroudly/issues/11), for one) got only that, and stayed blocked. Now the real packet is cut, one byte into the name and in the middle of the site's own name (`dis|cord`), so no piece carries the whole name. Every server puts the pieces back together, so sites that opened before keep opening. On by default; it can also send the last piece first. It is tested on a real packet path in every test run: a router that drops any packet carrying a blocked name, and the engine in between. Windows x64 and Linux.
- **Advanced mode on Windows starts reliably from any folder.** Its arguments are now quoted exactly by Windows' own rules, so a path with unusual characters can never reach the elevated engine changed (found by the new code scanning).
- **A window closed before it appeared stays closed.** Closing Shroudly's window to the background in the first moment after opening it could make it pop up again a moment later.

Thanks to **[Yiğit Efe Avcı](https://github.com/yigit433)** for pointing out, in [#13](https://github.com/umutxyp/Shroudly/pull/13), that Advanced mode sent the real first packet whole, which led to this cut.

Everything from [2.5.8](https://github.com/umutxyp/Shroudly/releases/tag/v2.5.8) is included. Users of 2.0.4 and later update automatically.
