## Shroudly 2.4.2

- **Encrypted DNS turns itself back on when it is needed.** If a site cannot be opened with encrypted DNS switched off, Shroudly switches it back on, restarts protection and tells you.
- **"Works in the browser, not in the Discord app."** When Discord has to be restarted, the window now explains why: Discord's updater does not use the system proxy. Where the computer has Advanced mode, it is offered; on macOS, the web version is suggested. (2.4.3 solves this properly with Discord app mode.)
- **Site test no longer contradicts itself** when Advanced mode is on.
- **Arch Linux installs now update automatically.** The `.pacman` package was missing from the update feed.
- Two log lines that were still in English in every language are translated.

> **Superseded by [2.4.3](https://github.com/umutxyp/Shroudly/releases/tag/v2.4.3)**, which also fixes the Windows installer closing without installing on some first installs. Please use 2.4.3.
