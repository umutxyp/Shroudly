## Shroudly 2.6.9

**Sites with many server names (such as YouTube's video servers) get every technique tried, and on Android the numbers follow the language you chose.**

### Sites with many names ([#37](https://github.com/umutxyp/Shroudly/issues/37))
- When a blocked site is spread over many server names, as YouTube's videos are (`rr1---sn-….googlevideo.com`, `rr2---…` and so on), each name used to start the list of techniques from the top. On a network that drops connections silently, each one ran out of time after the same first few, so the rest were never tried.
- Now the next name of the site carries on where the last one stopped. Across a site's names every technique gets its turn, and once one works it is used for the whole site.

### Android
- With a language chosen in Settings (on Android 12 and earlier), numbers such as the connection count, uptime and data now use that language's digits too, not the phone's ([#38](https://github.com/umutxyp/Shroudly/issues/38)).

Everything from [2.6.8](https://github.com/umutxyp/Shroudly/releases/tag/v2.6.8) is included: the system's DNS no longer sees the sites you open, plain UDP to your own DNS server is asked again on loss. Desktop users update automatically; the Android app tells you that 2.6.9 is out.
