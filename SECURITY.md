# Security policy

## Supported versions

Only the [latest release](https://github.com/umutxyp/Shroudly/releases/latest) is supported. Shroudly updates itself, so fixes reach users as a normal update.

## Reporting a vulnerability

Please **do not open a public issue** for anything that could harm users. Report it privately through GitHub:

**<https://github.com/umutxyp/Shroudly/security/advisories/new>**

Include what is affected (the app, the `shroudly-core` engine, Advanced mode, the installers, the update feed, the site list or the stats server), the version and OS, and the steps to reproduce. You will get an answer within a few days; a confirmed issue is fixed in a release, and you are credited unless you prefer not to be.

## Where Shroudly comes from

Shroudly is published only on this repository's [Releases](https://github.com/umutxyp/Shroudly/releases) page and at <https://shroudly.codeshare.me>, built from this source by GitHub Actions. The Windows installers are being set up for code signing through SignPath Foundation (see the [code signing policy](README.md#code-signing-policy)). Copies from anywhere else, and anyone asking for passwords, tokens or to run a file on their behalf, are not from this project.
